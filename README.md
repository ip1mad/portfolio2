# Ahmad Portfolio

Personal developer portfolio website for Ahmad, focused on backend engineering and project storytelling.

## Run locally

Open `/home/runner/work/portfolio2/portfolio2/index.html` in a browser.

Or serve it with a static server:

```bash
cd /home/runner/work/portfolio2/portfolio2
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
